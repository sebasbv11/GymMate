# GymMate

GymMate es una aplicación móvil nativa que funciona como asistente personal de gimnasio. Permite consultar ejercicios, organizar rutinas, acompañar entrenamientos y visualizar el progreso del usuario.

## Segunda etapa

El objetivo de esta etapa es construir un MVP navegable a partir del prototipo de alta fidelidad.

- Kotlin.
- Jetpack Compose.
- Material Design 3.
- Navegación con `NavController`.
- Interfaz adaptable.
- Datos simulados durante esta etapa.

La conexión con una base de datos en la nube y los tutoriales de YouTube quedan fuera del alcance del entregable actual.
